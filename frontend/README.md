# Diabetic Patient Management System - Frontend

This is the frontend for the Diabetic Patient Management System, built with Next.js, TypeScript, and Tailwind CSS.

## Getting Started

1.  **Install Dependencies:**
    Open a terminal in this folder (`frontend`) and run:

    ```bash
    npm install
    # or
    yarn install
    ```

2.  **Run the Development Server:**

    ```bash
    npm run dev
    # or
    yarn dev
    ```

3.  **Open the Application:**
    Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Features Implemented (UI Shell)

- **Dashboard:** Overview of key metrics (Total Patients, Appointments, High Risk Alerts).
- **Patient Management:** List view of patients with search and filter capabilities.
- **Sidebar Navigation:** Easy access to all system modules.

## Project Structure

- `src/app`: Contains the page routes and layouts.
- `src/components`: Reusable UI components (Sidebar, etc.).
- `public`: Static assets.

## Tech Stack

- **Framework:** Next.js 14
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
